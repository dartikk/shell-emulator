# Эмулятор командной оболочки ОС

## Вариант №27

Этап 1 — REPL.

## 1. Общее описание

Проект представляет собой минимальный прототип эмулятора командной оболочки UNIX-подобной операционной системы.

Эмулятор реализован на языке Python в форме графического интерфейса (GUI). Пользователь может вводить команды в интерактивном режиме и получать результаты их выполнения.

На первом этапе реализованы базовые возможности командной оболочки:

* графический интерфейс;
* приглашение командной строки;
* получение имени пользователя и имени компьютера из операционной системы;
* разбор введённой строки на команду и аргументы;
* обработка неизвестных команд;
* обработка неверных аргументов;
* команда-заглушка `ls`;
* команда-заглушка `cd`;
* команда `exit`;
* история введённых команд.

Большинство команд на данном этапе являются заглушками. Их полноценная реализация будет выполнена на следующих этапах проекта.

## 2. Функции и настройки

### Графический интерфейс

После запуска открывается окно эмулятора командной оболочки.

Заголовок окна формируется на основе имени пользователя и имени компьютера текущей операционной системы:

```text
Эмулятор - [username@hostname]
```

Приглашение командной строки имеет вид:

```text
username@hostname:~$
```

### Парсер команд

Введённая пользователем строка разделяется на имя команды и аргументы по пробелам.

Например:

```text
ls -l docs
```

разбирается следующим образом:

```text
Команда: ls
Аргументы: -l docs
```

Пустая строка не считается командой.

### Команда `ls`

На первом этапе является командой-заглушкой.

Команда выводит своё имя и переданные аргументы.

Пример:

```text
ls
```

Результат:

```text
ls: аргументы = []
```

При передаче аргументов:

```text
ls -l docs
```

результат содержит имя команды и переданные аргументы.

Полноценная работа с файловой системой на данном этапе не выполняется.

### Команда `cd`

На первом этапе является командой-заглушкой.

Пример:

```text
cd /tmp
```

Команда выводит своё имя и переданный аргумент.

При передаче нескольких аргументов выводится сообщение об ошибке:

```text
cd: too many arguments
```

Полноценная смена директории на данном этапе не выполняется.

### Команда `exit`

Используется для завершения работы эмулятора.

Пример:

```text
exit
```

После выполнения команды графическое окно закрывается.

При передаче аргументов выводится ошибка:

```text
exit: too many arguments
```

### Обработка неизвестных команд

Если введённая команда отсутствует среди поддерживаемых команд, выводится сообщение:

```text
command: command not found
```

Например:

```text
abc
```

Результат:

```text
abc: command not found
```

### История команд

Введённые команды сохраняются в истории.

Для навигации по истории используются клавиши:

* `↑` — предыдущая команда;
* `↓` — следующая команда.

История позволяет повторно выбрать ранее введённую команду.

## 3. Сборка и запуск проекта

Для работы проекта требуется Python 3 с доступным модулем `tkinter`.

### Linux/macOS

Для запуска приложения:

```bash
./run.sh
```

Для запуска тестов:

```bash
./run.sh test
```

### Windows

Для запуска приложения:

```bat
run.bat
```

Для запуска тестов:

```bat
run.bat test
```

Тесты запускаются с использованием стандартного модуля Python `unittest`.

## 4. Примеры использования

### Запуск эмулятора

После запуска отображается приглашение:

```text
username@hostname:~$
```

где `username` и `hostname` определяются на основе данных текущей операционной системы.

### Выполнение `ls`

Ввод:

```text
ls
```

Результат:

```text
ls: аргументы = []
```

### Выполнение `ls` с аргументами

Ввод:

```text
ls -l docs
```

Результат содержит:

```text
ls
```

и переданные аргументы:

```text
-l docs
```

### Выполнение `cd`

Ввод:

```text
cd /tmp
```

Команда обрабатывается как команда-заглушка и выводит имя команды и аргумент.

### Ошибка аргументов

Ввод:

```text
cd /tmp/test
```

с одним аргументом является допустимым.

При вводе:

```text
cd /tmp test
```

выводится:

```text
cd: too many arguments
```

### Неизвестная команда

Ввод:

```text
hello
```

Результат:

```text
hello: command not found
```

### Завершение работы

Ввод:

```text
exit
```

завершает работу эмулятора.

При вводе:

```text
exit now
```

выводится:

```text
exit: too many arguments
```

### История команд

После выполнения нескольких команд клавиша `↑` позволяет перейти к предыдущей команде, а клавиша `↓` — к следующей.

Таким образом, прототип поддерживает интерактивный диалог с пользователем и демонстрирует всю функциональность, предусмотренную для этапа 1.
